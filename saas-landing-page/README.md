# NOVA — SaaS Landing Page Concept

A responsive landing page concept for a fictional productivity workspace called NOVA. Built to showcase frontend layout and styling skills.

## Built with
- HTML5
- CSS3 (responsive layouts, grid, flexbox, gradients, media queries)
- Vanilla JavaScript (mobile navigation, FAQ interaction, current year)

## Showcase sections
- Hero section with a CSS-built product mockup
- Feature cards and product workflow
- Pricing concept (clearly labeled as sample pricing)
- FAQ accordion
- Call-to-action and footer

## Important notes
NOVA is a fictional concept project, not a real SaaS product. Pricing and product details are illustrative. The contact email uses a placeholder address and should be replaced before using this as a real business website.
